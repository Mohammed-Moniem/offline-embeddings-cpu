Complete offline CPU embedding and SQLite retrieval packages for Windows x64 and macOS Apple Silicon.

Download the ZIP for your operating system, its SHA-256 checksum file, and its target verification report. The ZIP contains Node, production dependencies/native libraries, the pinned BGE-small-en-v1.5 quantized model, tokenizer/configuration, application source, launchers and licenses. The automatically generated source archives are not complete runtime packages.

The release workflow verifies each ZIP after a fresh extraction using its bundled runtime with OS-level network denial. Read the attached target report for the exact archive hash and results. CLI ingestion supports UTF-8 text and Markdown; applications can pass text extracted from other formats through the JavaScript API.
